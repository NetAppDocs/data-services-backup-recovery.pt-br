= Faça backup de cargas de trabalho do KVM com o NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Faça backup de grupos de proteção KVM de sistemas ONTAP no local para Amazon Web Services, Azure NetApp Files ou StorageGRID. Ao fazer backup de um grupo de proteção, o NetApp Backup and Recovery faz backup das máquinas virtuais e dos pools de storage desse grupo e armazena o backup em um armazenamento de objetos na sua conta de nuvem pública ou privada.


NOTE: Para executar backups agendados, crie políticas que controlem as operações de backup e restauração. Consulte link:br-use-policies-kvm-create.html["Crie políticas de proteção KVM"] para obter instruções.

* Crie grupos de proteção para gerenciar as operações de backup e restauração de um conjunto de recursos. Consulte link:br-use-kvm-protection-groups.html["Gerencie grupos de proteção KVM em NetApp Backup and Recovery"] para mais informações.




[[back-up-protection-groups-now-with-an-on-demand-backup]]
== Faça backup de grupos de proteção agora com um backup sob demanda

Execute um backup sob demanda imediatamente se você estiver prestes a fazer alterações e quiser ter um backup atual primeiro.

*Função necessária do NetApp Console*: superadministrador de Backup and Recovery ou administrador de backup de Backup and Recovery https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu do NetApp Console , selecione *Proteção > Backup e recuperação*.
. No bloco KVM, selecione *Descobrir e gerenciar*.
. Selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes de proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a guia *Grupos de proteção*, *Datastores* ou *máquinas virtuais*.
. Selecione o grupo de proteção que você deseja fazer backup.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Faça backup agora*.
+

NOTE: A política aplicada ao backup é a mesma política atribuída ao grupo de proteção.

. Selecione o nível de agendamento.
. Selecione *Fazer backup*.
