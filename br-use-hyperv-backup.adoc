= Faça backup de cargas de trabalho do Hyper-V com o NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Faça backup de máquinas virtuais Hyper-V de sistemas ONTAP locais para destinos de storage de objetos compatíveis para proteger seus dados. Os backups agendados e sob demanda são armazenados na sua nuvem ou em seu armazenamento de objetos privado.

* Para fazer backup de cargas de trabalho em um cronograma, crie políticas que controlem as operações de backup e restauração.  Verlink:br-use-policies-create.html["Criar políticas"] para obter instruções.
* Crie grupos de proteção para gerenciar as operações de backup e restauração de um conjunto de recursos. Consulte link:br-use-hyperv-protection-groups.html["Crie e gerencie grupos de proteção do Hyper-V em NetApp Backup and Recovery"] para mais informações.
* Faça backup de suas cargas de trabalho agora mesmo com um backup sob demanda.




[[back-up-workloads-now-with-an-on-demand-backup]]
== Faça backup de cargas de trabalho agora com um backup sob demanda

Utilize um backup sob demanda para proteger seus dados antes de fazer alterações no sistema.

*Função necessária do NetApp Console*: superadministrador de Backup and Recovery ou administrador de backup de Backup and Recovery https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu NetApp Backup and Recovery , selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes da proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a guia *Grupos de proteção*, *Datastores* ou *máquinas virtuais*.
. Selecione o grupo de proteção ou as máquinas virtuais que você deseja fazer backup.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Faça backup agora*.
+

NOTE: O backup usa a mesma política que você atribuiu ao grupo de proteção ou à máquina virtual.

. Selecione o nível de agendamento.
. Selecione *Fazer backup*.
