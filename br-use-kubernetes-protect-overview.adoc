= Fluxo de trabalho de proteção do Kubernetes com o NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Use o NetApp Backup and Recovery para descobrir, gerenciar e proteger clusters e aplicativos Kubernetes a partir de uma única interface.

O diagrama a seguir mostra os componentes e a arquitetura básica para backup e recuperação do Kubernetes e como cópias dos seus dados podem ser armazenadas em locais diferentes:

image:../media/backup-recovery-architecture-diagram.png["Diagrama de arquitetura de backup e recuperação para cargas de trabalho do Kubernetes"]

O NetApp Backup and Recovery oferece os seguintes benefícios para o gerenciamento de cargas de trabalho do Kubernetes:

* Um único plano de controle para proteger aplicações em múltiplos clusters Kubernetes, incluindo contêineres e máquinas virtuais.
* A integração nativa com a NetApp SnapMirror permite o descarregamento de storage para fluxos de trabalho de backup e recuperação.
* Backups incrementais permanentes para aplicativos Kubernetes, o que se traduz em Objetivos de Ponto de Recuperação (RPOs) e Objetivos de Tempo de Recuperação (RTOs) mais baixos.
