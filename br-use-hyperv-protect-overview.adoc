= Proteja as cargas de trabalho do Hyper-V com o NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Use o NetApp Backup and Recovery para fazer backup e restaurar VMs Hyper-V independentes, instâncias de cluster de failover e VMs provisionadas pelo SCVMM hospedadas em um compartilhamento CIFS.

Você pode fazer backup de cargas de trabalho do Hyper-V no Amazon S3 ou no StorageGRID e restaurá-las em um host Hyper-V no local.

Use o NetApp Backup and Recovery para implementar uma estratégia de proteção 3-2-1, com três cópias dos seus dados de origem em dois sistemas de armazenamento diferentes e uma cópia na nuvem. Os benefícios da abordagem 3-2-1 incluem:

* Várias cópias de dados protegem contra ameaças internas e externas à segurança cibernética.
* Vários tipos de mídia mantêm a viabilidade de failover caso um deles apresente falha física ou lógica.
* A cópia no local ajuda você a restaurar os dados rapidamente, e você pode usar as cópias externas caso a cópia no local seja comprometida.


Ao adicionar hosts Hyper-V e descobrir recursos, o NetApp Backup and Recovery instala o NetApp Hyper-V plug-in e o NetApp SnapCenter Windows FileSystem plug-in em cada host Hyper-V para ajudar a gerenciar e proteger máquinas virtuais.
