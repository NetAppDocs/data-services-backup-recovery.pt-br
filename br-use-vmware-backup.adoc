= Faça backup de cargas de trabalho do VMware com o NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Faça backup de VMs e datastores VMware de sistemas ONTAP locais para Amazon Web Services, Azure NetApp Files ou StorageGRID para garantir que seus dados estejam protegidos. Os backups são gerados automaticamente e armazenados em um armazenamento de objetos na sua conta de nuvem pública ou privada.

* Para fazer backup de cargas de trabalho de forma programada, crie políticas que controlem as operações de backup e restauração. Consulte link:br-use-policies-create.html["Criar políticas de proteção"] para obter instruções.
* Crie grupos de proteção para gerenciar as operações de backup e restauração de um conjunto de recursos. Veja link:br-use-vmware-protection-groups.html["Criar e gerenciar grupos de proteção"] para mais informações.
* Faça backup das cargas de trabalho agora (crie um backup sob demanda agora).




[[back-up-workloads-now-with-an-on-demand-backup]]
== Faça backup de cargas de trabalho agora com um backup sob demanda

Crie um backup sob demanda imediatamente.  Talvez você queira executar um backup sob demanda se estiver prestes a fazer alterações no seu sistema e quiser garantir que tenha um backup antes de começar.

*Função necessária do NetApp Console*: Storage viewer, Backup and Recovery super admin, Backup and Recovery backup admin, Backup and Recovery restore admin, Backup and Recovery clone admin ou Backup and Recovery viewer role. Se você estiver protegendo dados armazenados em um cluster Cloud Volumes ONTAP, a função Cloud Volumes ONTAP Admin também é necessária https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu Backup e Recuperação, selecione *Inventário*.
. Selecione a carga de trabalho do VMware.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione o cabeçalho de menu *Grupos de Proteção*, *Datastores*, *Máquinas virtuais* ou *Tags*.
. Selecione o grupo de proteção, os datastores, as máquinas virtuais ou os recursos etiquetados que você deseja fazer backup.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Faça backup agora*.
+

NOTE: A política aplicada ao backup é a mesma política atribuída ao grupo de proteção, datastore, máquina virtual ou aos recursos etiquetados.

. Selecione o nível de agendamento.
. Selecione *Fazer backup agora*.




[[delete-backups]]
== Excluir backups

Você pode excluir backups locais que não são mais necessários para liberar espaço de storage ou atender aos requisitos de retenção de dados.

.Passos
. Faça login no NetApp Backup and Recovery e, na tela inicial, selecione o bloco da carga de trabalho do VMware.
+
A página de inventário da VMware é exibida.

. Selecione o cabeçalho *Máquinas virtuais*.
. Na lista de máquinas virtuais, escolha uma máquina virtual e selecione o ícone Ações image:../media/icon-action.png["Opção de ações"] > *Exibir detalhes de proteção*.
. Selecione um período de tempo para exibir os snapshots relevantes.
. Excluir um ou mais snapshots:
+
[role="tabbed-block"]
====
.Excluir um único snapshot
--
.. Escolha um instantâneo da lista que você deseja excluir e selecione o ícone Ações image:../media/icon-action.png["Opção de ações"] > *Excluir instantâneo local*.


--
.Excluir vários instantâneos
--
.. Selecione a caixa de seleção à esquerda de cada snapshot que você deseja excluir.
.. Selecione *Excluir selecionados*.


--
====
