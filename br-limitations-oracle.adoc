= Limitações conhecidas com NetApp Backup e Recovery para cargas de trabalho do Oracle Database
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Analise as limitações atuais e as ações não suportadas para cargas de trabalho do Oracle Database em NetApp Backup and Recovery.

As seguintes ações não são suportadas para cargas de trabalho do Oracle Database na versão prévia do NetApp Backup and Recovery:

* Na versão prévia de Backup and Recovery para implantação local do NetApp Console, os backups para storage de objetos são suportados apenas para destinos ONTAP S3 e StorageGRID. O arquivamento de backup não é suportado nesta versão prévia.
* Backups offline
