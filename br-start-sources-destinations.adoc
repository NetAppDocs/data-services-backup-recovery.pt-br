[[supported-systems-for-backup-and-restore-operations]]
== Sistemas suportados para operações de backup e restauração

O NetApp Backup and Recovery oferece suporte a sistemas ONTAP e provedores de nuvem pública e privada.



[[supported-regions]]
=== Regiões suportadas

O NetApp Backup and Recovery é compatível com o Cloud Volumes ONTAP em muitas regiões da Amazon Web Services, Microsoft Azure e Google Cloud.

https://bluexp.netapp.com/cloud-volumes-global-regions["Saiba mais usando o Mapa de Regiões Globais"^]



[[supported-backup-destinations]]
=== Destinos de backup suportados

O NetApp Backup and Recovery permite fazer backup de dados dos seguintes sistemas de origem para os seguintes sistemas secundários e storage de objetos em provedores de nuvem pública e privada. Os snapshots residem no sistema de origem.


NOTE: Atualmente, a Wasabi é a única provedora de storage de objetos compatível com S3 qualificada. Outros provedores compatíveis com S3 ainda não foram validados.

[[supported-restore-destinations]]
=== Destinos de restauração suportados

Você pode restaurar dados de um arquivo de backup, máquina virtual, banco de dados ou recurso do Kubernetes que reside em um sistema secundário (um volume replicado) ou em storage de objetos (um arquivo de backup) para os seguintes sistemas. Os snapshots residem no sistema de origem e só podem ser restaurados para esse mesmo sistema.

Tenha em mente as seguintes considerações sobre restauração:

* Restaurações do Cloud Volumes ONTAP (replicação) só podem ser feitas para o Cloud Volumes ONTAP. No entanto, o Cloud Volumes ONTAP na AWS também oferece suporte à restauração para o Amazon FSx for NetApp ONTAP.
* As restaurações do ONTAP local (replicação) só podem ser feitas para o ONTAP local.
* As restaurações de soluções próprias do Amazon FSx for NetApp ONTAP e do Google Cloud NetApp Volumes (replicação) só podem ser feitas no respectivo sistema próprio.
* A restauração do Amazon S3 para o Amazon FSx for NetApp ONTAP deve seguir esta ordem: do Amazon S3 para o Cloud Volumes ONTAP e, em seguida, do Cloud Volumes ONTAP para o Amazon FSx for NetApp ONTAP.



NOTE: As referências a "sistema ONTAP local" incluem os sistemas FAS, AFF e ONTAP Select.
