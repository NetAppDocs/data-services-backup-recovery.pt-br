= Faça backup das cargas de trabalho do Oracle Database usando NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Faça backup de grupos de proteção do Oracle Database ou de bancos de dados individuais de sistemas ONTAP locais usando o NetApp Backup and Recovery. Envie backups para storage de nuvem, incluindo Amazon S3, NetApp StorageGRID, Microsoft Azure Blob Storage ou ONTAP S3.


NOTE: Para fazer backup de grupos de proteção ou bancos de dados individuais em um agendamento, crie políticas que gerenciem operações de backup e restauração. Verlink:br-use-policies-create.html["Criar políticas"] para obter instruções.

* Crie grupos de proteção para gerenciar as operações de backup e restauração de um conjunto de recursos. Veja link:br-use-kvm-protection-groups.html["Crie e gerencie grupos de proteção para cargas de trabalho do Oracle Database com NetApp Backup e Recovery"] para mais informações.
* Crie um backup sob demanda de um grupo de proteção.
* Crie um backup sob demanda de um banco de dados.




[[create-an-on-demand-backup-of-a-protection-group]]
== Crie um backup sob demanda de um grupo de proteção

Crie um backup sob demanda antes de fazer alterações no sistema para proteger seus dados.

*Função necessária do NetApp Console*: superadministrador de Backup and Recovery ou administrador de backup de Backup and Recovery https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu do NetApp Console , selecione *Proteção > Backup e recuperação*.
. Em *Cargas de trabalho*, selecione o bloco *Oracle*.
. Selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes da proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a guia *Grupos de Proteção*.
. Selecione o grupo de proteção que você deseja fazer backup.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Faça backup agora*.
+

NOTE: O NetApp Backup and Recovery usa a mesma política para o backup e o grupo de proteção.

. Selecione o nível de agendamento.
. Selecione *Fazer backup*.




[[create-an-on-demand-backup-of-a-database]]
== Crie um backup sob demanda de um banco de dados

Crie um backup sob demanda antes de fazer alterações no sistema para proteger seus dados.

*Função necessária do NetApp Console*: superadministrador de Backup and Recovery ou administrador de backup de Backup and Recovery https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu do NetApp Console , selecione *Proteção > Backup e recuperação*.
. Em *Cargas de trabalho*, selecione o bloco *Oracle*.
. Selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes da proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a aba *Bancos de dados*.
. Selecione o banco de dados que você deseja fazer backup.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Faça backup agora*.
. Selecione o nível de agendamento.
. Selecione *Fazer backup*.
