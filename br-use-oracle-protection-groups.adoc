= Crie e gerencie grupos de proteção para cargas de trabalho do Oracle Database com NetApp Backup e Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Crie grupos de proteção para gerenciar as operações de backup dos recursos do Oracle Database. Um grupo de proteção é um agrupamento lógico de recursos, como bancos de dados, que você deseja proteger em conjunto.

Você pode executar as seguintes tarefas relacionadas a grupos de proteção:

* Crie um grupo de proteção.
* Ver detalhes da proteção.
* Faça backup de um grupo de proteção agora. Veja link:br-use-oracle-backup.html["Faça backup das cargas de trabalho do Oracle Database agora"].
* Excluir um grupo de proteção.




[[create-a-protection-group]]
== Crie um grupo de proteção

Agrupe os recursos do Oracle Database que você deseja proteger juntos em um grupo de proteção.

*Função necessária do NetApp Console*: superadministrador de Backup and Recovery ou administrador de backup de Backup and Recovery https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Saiba mais sobre as funções de acesso do NetApp Console para todos os serviços"^].

.Passos
. No menu NetApp Backup and Recovery , selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes da proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a aba *Grupos de proteção*.
. Selecione *Criar grupo de proteção*.
. Forneça um nome para o grupo de proteção.
. Selecione os bancos de dados que você deseja incluir no grupo de proteção.
+
Os bancos de dados em espera não são listados por padrão. Para listá-los, selecione *Mostrar bancos de dados standby do Data Guard*. Se você selecionar um banco de dados que faça parte de uma configuração do Oracle Data Guard, o NetApp Backup and Recovery também adiciona o outro banco de dados na mesma configuração. Isso só ocorre se esse banco de dados for detectado, puder ser protegido e não estiver em outro grupo de proteção.

. Selecione *Avançar*.
. Selecione a *Política de backup* a ser aplicada ao grupo de proteção. Se o grupo incluir bancos de dados do Oracle Data Guard, use as *Configurações do Data Guard* na política para escolher quais bancos de dados terão backup. Consulte link:br-use-policies-oracle-create.html["Criar e gerenciar políticas de backup do Oracle Database"].
+
Se você quiser criar uma política, selecione *Criar nova política* e siga as instruções para criar uma política.  Verlink:br-use-policies-create.html["Criar políticas"] para mais informações.

. Selecione *Avançar*.
. Revise a configuração.
. Selecione *Criar* para criar o grupo de proteção.



NOTE: Se você adicionar o host de espera depois de criar o grupo de proteção, edite o grupo de proteção e salve-o. O NetApp Backup and Recovery adiciona o host de espera automaticamente. No host de espera, adicione ao grupo apenas os bancos de dados de espera. Outro banco de dados desse host que precise de um tipo de backup diferente fará com que o backup falhe para esse host.



[[delete-a-protection-group]]
== Excluir um grupo de proteção

A exclusão de um grupo de proteção o remove, juntamente com todos os agendamentos de backup associados. Talvez você queira excluir um grupo de proteção se ele não for mais necessário.

.Passos
. No menu NetApp Backup and Recovery , selecione *Inventário*.
. Selecione uma carga de trabalho para visualizar os detalhes da proteção.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Ver detalhes*.
. Selecione a aba *Grupos de proteção*.
. Selecione o grupo de proteção que você deseja excluir.
. Selecione o ícone Açõesimage:../media/icon-action.png["Opção de ações"] > *Remover proteção*.
. Revise a mensagem de confirmação sobre a exclusão dos backups associados e confirme a exclusão.
