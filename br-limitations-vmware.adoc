= Limitações conhecidas para cargas de trabalho VMware em NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Analise estas limitações antes de usar o NetApp Backup and Recovery para cargas de trabalho VMware.

NetApp Backup and Recovery não oferece suporte às seguintes ações para cargas de trabalho VMware:

* Na versão prévia de Backup and Recovery para implantação local do NetApp Console, os backups para storage de objetos são suportados apenas para destinos ONTAP S3 e StorageGRID. O arquivamento de backup não é suportado nesta versão prévia.
* Suporte vVol
* Integração de e-mail
* Suporte ao controle de acesso baseado em função (RBAC)
